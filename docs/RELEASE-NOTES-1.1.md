# 简记 1.1 发布说明

## 新增功能

- **周期账单**：房租、订阅、工资等固定收支，设置一次自动记账。到期账单在打开 App 时自动补记，无需后台运行，重复打开也不会重复记。支持每天 / 每周 / 每月，可暂停、编辑、删除。
- **预算提醒**：本月支出达预算 80% 与超支时，各推送一次本地通知。隐私账单不计入、不出现在锁屏。可在「设置 → 月度预算」开启。
- **桌面小组件**：小号 / 中号组件显示本月支出、收入与预算进度，一眼可见。记账后自动刷新。
- **iCloud 同步**：开启后账单通过你自己的 iCloud 在多设备间同步，换机不丢数据。全程无账号、无自建服务器。
- **账单搜索**：明细页顶部放大镜进入，按备注 / 分类 / 金额搜索，支持全部 / 支出 / 收入筛选，显示结果笔数与收支合计。
- **图表趋势**：图表页新增「近半年收支趋势」，6 个月支出与收入分组柱状对比。

## 体验优化

- 明细支出金额标红，收支一眼分清。
- 记账页金额用自带数字键盘、备注用系统中文输入法，两者互斥不再打架。
- 金额支持光标定位，点中间任意一位即可插入 / 删除，改错不用全删重打。
- 启动页统一为「¥ + 简记」居中锁定版式，冷启动无跳变、不再白屏。

## 隐私说明（App Store 隐私清单参考）

- 不收集任何用户数据，无第三方 SDK、无广告、无追踪。
- 账单数据仅存于设备本地；开启 iCloud 后经用户自己的私有 iCloud（CloudKit）同步，开发者无法访问。
- 语音识别优先本机完成；截图识别（OCR）完全在本机进行，图片不上传。
- 需要的系统权限：麦克风与语音识别（语音记账）、通知（预算提醒）、Face ID（隐私锁 / 隐私账本）。
